## Real public API access remains blocked here

The original HTTPS geocoding probe, using the inherited proxy and TLS verification,
returned `CONNECT tunnel failed, response 403` in an approved outer-executor retry.
The applied policy did not contain the requested public-service destinations.
This demonstrates an environment access problem, not a provider outage.

The new interface was also tested with a real **live-mode attempt**. It displayed:

- The destination request as a local completed step.
- A failed Open-Meteo request with its exact source URL.
- A terminal planning failure, with no substitute demo itinerary.

The attempted URL was:

```text
https://geocoding-api.open-meteo.com/v1/search?name=Chicago&count=1&language=en&format=json
```

No successful real geocoding/place/route response is claimed in this cloud instance.
Four destinations were saved in an environment configuration draft:

- `geocoding-api.open-meteo.com`
- `nominatim.openstreetmap.org`
- `overpass-api.de`
- `router.project-osrm.org`

At the last runtime observation, the applied custom allowlist remained empty.
Review/save the environment changes and publish them, then refresh runtime status
and run `python -m scripts.smoke_live --destination Chicago`. Do not infer access
from a saved draft. The opt-in script exits nonzero if an essential service fails.

Mocked provider tests cover response parsing, missing/malformed data, timeouts,
cache/rate limits, website tags and source records. They verify our adapter logic,
not the availability or correctness of a live provider.

## Current model and booking boundary

No LLM is connected. OpenAI-specific code from the initial prototype was removed
in favor of a free-only, rule-based baseline. Unsupported planner names are rejected.
There are no model API credentials or model requests in this version.

Source website links are references, with `website_checked=false`. Preparation
items use `booking_required=null` and `availability_checked=false`; the application
has not checked ticket inventory or actually booked anything.
